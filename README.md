# sudo-kaneki.github.io

Personal site of Writabrata Bhattacharya — home page, CV, projects, and blog.

Built with Jekyll on a custom retro-modern theme: no CSS/JS framework, no
Bootstrap, no jQuery. Originally scaffolded from
[al-folio](https://github.com/alshedivat/al-folio), whose theme and docs have
since been fully replaced with a hand-built design system.

## Stack

- **Jekyll**, 7 plugins (`jekyll-feed`, `jekyll-sitemap`, `jekyll-minifier`, etc.)
- **SCSS** compiled from `_sass/`, driven entirely by design tokens in `_sass/_tokens.scss`
- Plain **JavaScript** for the theme toggle and blog filter
- **RenderCV** to generate the CV PDF from `_data/cv.yml`

## Local development

The Docker image ships with gems pre-installed. Only ever build with:

```bash
docker compose run --rm jekyll bundle exec jekyll build --trace
```

`docker compose up --build` and a bare `bundle install` both rewrite the gem
environment and break the build — don't run either. To browse the site
locally, `docker compose up` (without `--build`) serves it at
http://localhost:8080.

Before committing, format everything:

```bash
npx prettier . --write
```

## `cv.yml` is the source of truth

`_data/cv.yml` feeds three outputs: the `/cv/` page, the homepage timeline,
and the CV PDF (regenerated by `.github/workflows/render-cv.yml` on every push
that touches it). Career history is edited in exactly one place.
